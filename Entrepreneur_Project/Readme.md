# PCForge — E‑Commerce Web Project

A front‑end focused e‑commerce website project built with **HTML, CSS, JavaScript, and PHP**, designed to simulate a custom PC parts store experience. This project demonstrates responsive layout design, dynamic cart functionality, and multi‑page site structure without using frameworks.

---

## 📁 Project File Structure

```
About me!.html
cart.html
cart.js
data.js
index.html
index.js
latest-news.html
latest-news.js
products.html
productsp.html
register.php
Return-Policy.html
style.css
warranty.html
```

---

## 🧩 Page Overview

### 🏠 `index.html`

* Landing page for PCForge
* Highlights featured products and promotions
* Uses `index.js` for dynamic behaviors

### 👤 `About me!.html`

* About section explaining the brand / creator
* Styled using the shared `style.css`

### 🛒 `cart.html`

* Shopping cart interface
* Dynamically updated using `cart.js`
* Displays selected products, quantities, and pricing

### 🧠 `data.js`

* Stores product data used across the site
* Acts as the single source of truth for products

### 📰 `latest-news.html`

* Displays updates and announcements
* Powered by `latest-news.js`

### 🛍️ `products.html` & `productsp.html`

* Product listing and product‑related views
* Integrated with cart functionality

### 🧾 `register.php`

* Account registration page
* Demonstrates basic PHP form handling

### 📄 Policy Pages

* `Return-Policy.html`
* `warranty.html`

Provide store policies and customer information
